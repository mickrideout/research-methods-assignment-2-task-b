# reports/

Timestamped reports (`YYYYMMDD-HHMMSS.md`); nothing here is ever overwritten. Paths come from
`python3 tools/report_path.py <kind> [QID]`.

| Folder | Written by |
|---|---|
| `grading/<QID>/` | grade-question |
| `grading/assignment/` | grade-assignment |
| `compliance/` | check-compliance (`tools/compliance.py`) |
| `environment/` | check-environment |
| `presubmission/` | export-submission |

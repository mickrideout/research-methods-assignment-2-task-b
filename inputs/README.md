# inputs/

Everything the university gives you goes here, unedited. Agents treat this folder as
**read-only** and cite it as `inputs/<folder>/<file>#p.N`.

| Folder | What goes there |
|---|---|
| `spec/` | Assignment specification / brief |
| `rubric/` | Official marking rubric |
| `outcomes/` | Unit learning outcomes |
| `lectures/` | Slides, handouts, transcripts |
| `readings/` | Set readings and sources to cite |
| `clarifications/` | Forum / FAQ / announcement posts (dated .md files) |
| `feedback/` | Prior feedback and draft feedback |
| `exemplars/` | Exemplars and marked examples |
| `starter/` | Starter code (pristine) |
| `data/` | Datasets (git-ignored) |

Text is extracted to `context/extracted/` by `python3 tools/extract_inputs.py`.

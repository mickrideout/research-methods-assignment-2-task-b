Task A: Telling a Data Story

Data Sources and Dataset Selection

1. Are datasets from more than one source allowed?

Yes. Datasets may be combined, including datasets from different repositories, provided each repository is listed in the assignment instructions. Name and link each source, and briefly explain how the datasets were combined.

2. Is already aggregated data acceptable?

Yes. The data may already be aggregated, or aggregation may be carried out as part of the analysis if that suits the research question. Briefly note any preprocessing, such as aggregation, in the data-source description.

3. What source details are needed when several files are used?

Give the title and link for each data source. If several files come from the same source, list that source once; the specific fields used belong in the descriptive metrics section. If files come from different sources, give the title and link for each source.

4. Is one individual table/dataset enough for Task A?

Yes, if the table/dataset contains enough relevant data to complete the Task A requirements.

Research Question

5. What makes a research question focused enough for Task A?

A research question is a clear, focused and answerable question that sets the scope of an inquiry and guides data collection, analysis and interpretation. For Task A, it should guide the choice of data, metrics, visualisation and narrative. A question about a relationship can be suitable when its variables and scope are clear and supported by the data. For example, if the focus is on how closely trends align, the analysis needs to show what “closely” means. Keep the question under 50 words and explain detailed definitions or methods elsewhere.

Descriptive Metrics and Visualisation

6. How many metrics and charts are expected?

Choose two descriptive metrics that suit the research question. Additional metrics are allowed, but each one needs to be justified in the narrative. Task A asks for one appropriate visualisation; it may be presented as separate charts where needed. Annotate each chart fully and make sure to justify every metric and chart within the 200-word narrative limit.

7. Which tools may be used to create the visualisation?

Any suitable tool may be used, including R and ggplot2. Include the visualisation in the PDF and annotate it so the data, labels and important features are clear. Acknowledge the tool(s) used appropriately.

8. What belongs in the descriptive metrics section, and what counts toward its 50-word limit?

The requirement is to include the dataset fields used and the final calculated result for each selected metric. Words and numbers count toward the limit; table captions do not (if any). Use the word counter in the source document. Supporting full calculations may be included as an appendix (at the end of the file).

9. Where can the detailed calculations (for example, year-by-year results) go?

Report the final result for both metrics in the main section, within the 50-word limit. A full calculation table or detailed results (say, for each year) may go in an appendix, but the appendix does not replace the summary results required in the main section, on which basis the marks are awarded.

10. What is expected in the Task A narrative?

Interpret the selected data in relation to the research question and refer to the metrics and visualisation. Keep the narrative within 200 words, and justify any extra metrics or charts mentioned in the previous answers. The focus is on explaining the findings from the selected data, rather than writing a separate literature review.

File Naming

11. What filename format is recommended for the Task A PDF?

Use YourName-YourID-Assignment-2-Task-A.pdf, replacing the placeholders with the relevant name and student ID. The filename itself does not affect the mark, but the recommended format makes the submission easy to identify.

Task B: Working with Hypotheses

Statistical Tests

1. Which statistical tests are acceptable for Task B?

Any appropriate test may be used; the choice is not limited to the examples discussed in class. Explain why the test suits the proposed hypothesis and variables, state its assumptions, and describe how those assumptions can be important in choosing the test.

Alternative Narrative

2. What should the alternative narrative include when no data have been collected?

An alternative narrative should be more than simply stating one possible outcome of testing the null hypothesis or identifying a limitation of the research or test methods. It should refer to specific results from the previous Task B answers that would lead to a distinct alternative conclusion. It should also explain how the data, method(s), and/or processes used in the previous questions would need to be manipulated to produce those specific results when testing the null hypothesis.

In other words, describe a hypothetical result that could support a different conclusion. Then explain what would need to change in the proposed data selection, methods or processes to produce that result, including collecting new data if needed. Changes might involve using a different participant group, measuring a variable differently or applying another analysis method. Do not simply describe a possible null-hypothesis test outcome or repeat a study limitation.

Common Mistake/Tips: Discussion on future investigation should be related to addressing the limitations.

References for Tasks A and B

1. Are references required?

No. References are not required. If you happen to refer to published research papers or any other resources, you could cite using the APA 7 format. These references will not count towards the word count. 

  

Task C: Design for Effective Communication in Online Collaborations

Miro Board Access

1. What can resolve a Miro board creation or duplication limit?

First, make sure you sign up for a free account. The Miro Free plan allows up to three boards. From the Miro homepage, delete at least one existing board in the Free plan team to free a slot, then try again.

Board Structure and Export

2. What board structure is recommended for Task C?

Follow the assignment instructions properly. Use one Miro board for all of Task C. Put the C1 affinity diagram in one frame. For C2, the specification recommends five frames: three for brainstorming feature or interface ideas, how they work and how they address user needs, followed by two frames for the design solutions. Add annotations so the marker can follow the affinity diagramming and brainstorming process.

3. Is a 1 x PDF export acceptable if higher resolution is unavailable?

Yes, provided the content is clearly visible and readable. Use smaller frames rather than one oversized frame, which can lower export quality or cause parts of the board to be cut off.**

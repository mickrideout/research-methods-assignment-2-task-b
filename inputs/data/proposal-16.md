## 1. Proposed Hypothesis

Among non-home-owning Australians aged 18–30, the same participants will report higher state housing-related anxiety after viewing an algorithm-style curated housing-content feed than after viewing a randomly ordered feed of the same posts, in counterbalanced order.

## 2. Null Hypothesis

Within non-home-owning Australians aged 18–30, there is no difference in state housing-related anxiety between viewing an algorithm-style curated feed and a randomly ordered feed of the same content.

## 3. Independent, Dependent and Confounding Variables

**IV:** feed-ordering condition (algorithm-style vs random, within-subject, counterbalanced). **DV:** post-exposure state anxiety (VAS, 0–100). **Covariates:** condition order, baseline anxiety, and time between sessions.

## 4. Data Collection

Within-subject crossover experiment with 40 non-home-owning Australians aged 18–30, recruited via university networks and AUD $150 of advertising. Each participant views both a researcher-curated "high-engagement" feed and a randomly ordered version of the same 20 posts, one week apart, with order counterbalanced across participants; state anxiety is measured after each session. Participants receive a AUD $8 e-voucher per completed session, up to AUD $16 total each (AUD $640 for 40 participants), keeping total cost at AUD $790. Informed consent, debriefing, and voluntary withdrawal are provided at each session.

## 5. Statistical Tests

A paired-samples t-test compares each participant's state anxiety after the algorithm-style versus random feed, appropriate for a within-subject, two-condition comparison of one continuous outcome. Condition order is entered as a between-subjects covariate to check for carryover effects. Assumptions include normality of the paired differences (Shapiro-Wilk) and no substantial order effect (tested via independent t-test on order). If normality is violated, a Wilcoxon signed-rank test is used instead. Significance is set at α = .05, with a 95% confidence interval for the mean difference and Cohen's dz as the effect size. Counterbalanced random assignment of order supports a causal interpretation of the feed effect.

## 6. Limitations

A researcher-curated "algorithm-style" feed only approximates real platform personalisation (Li et al., 2026). One-week spacing may introduce memory or mood carryover despite counterbalancing. Convenience sampling limits generalisability. Attrition between sessions could bias the retained sample. A future study partnering with a platform's authentic recommendation system would improve ecological validity.

## 7. Alternative Narrative

A significant difference could be overstated as definitive proof algorithms 'cause' anxiety by ignoring possible order or novelty effects. Reporting only participants who completed both sessions with large differences would inflate the effect—a risk of selective analysis, not sound practice.
